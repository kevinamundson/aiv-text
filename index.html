Amundson Interpretive Version

WORK IN PROGRESS

The Amundson Interpretive Version (AIV) is an English Bible text under active revision. It is not finished, and its wording may change.

Each book is available as a USX file at /usx/{BOOK}.usx. Translation details are in metadata.json, a machine-readable book list is in books.json, and file checksums are in manifest.json.
